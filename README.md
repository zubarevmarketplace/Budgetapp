# Копилка — личный бюджет

Маленькое приложение для телефона: лимит «на ништяки», цели вроде «телефон до Нового года» и вклады с процентами.
Без сервера, без регистрации, без оплаты. Все записи хранятся только в телефоне.

## Как начать пользоваться

1. Открой ссылку в браузере телефона: **https://zubarevmarketplace.github.io/Budgetapp/**
2. Добавь на домашний экран, чтобы это было как обычное приложение:
   - iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“».
   - Android (Chrome): меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).
3. Во вкладке **Счета** поправь балансы: сколько сейчас на карте, на накопительном, на вкладах. У вклада укажи ставку — приложение покажет, сколько процентов капает в месяц.
4. Во вкладке **Цели** создай цель: название, сумма, срок.
5. Во вкладке **Ещё** поставь свой лимит на ништяки в месяц (по умолчанию 5 000 ₽) и число, с которого начинается твой месяц (например, день зарплаты).

## Каждый день

- Нажми **+** и запиши трату: сумма → категория → готово. Категории с пометкой «ништяки» уменьшают лимит, продукты и обязательные платежи — нет.
- Пришла зарплата — запиши доход. Начислили проценты по вкладу — запиши доход и поставь галочку «Это проценты по вкладу».
- Переложила деньги на накопительный — запиши перевод. Если перевод «на цель», прогресс цели вырастет, а приложение посчитает, когда накопишь.

## Раз в месяц: копия данных

Данные живут только в твоём телефоне. Во вкладке **Ещё** нажми «Сохранить копию» и положи файл в «Файлы», в облако или отправь себе в избранное Telegram. Если сменишь телефон, нажми «Восстановить» и выбери этот файл.

## Для разработчика

Vite + React + TypeScript, Tailwind CSS v4, Dexie (IndexedDB), vite-plugin-pwa. Код в `src/`:

- `db.ts` — схема данных, стартовые категории и счета, экспорт/импорт бэкапа.
- `lib/stats.ts` — балансы, итоги месяца, прогресс и прогноз целей.
- `lib/dates.ts` — «бюджетный месяц» с произвольным днём начала.
- `screens/` — экраны (Месяц, Цели, Счета, История, Ещё), `components/AddSheet.tsx` — форма записи.

```bash
npm install
npm run dev        # локально
npm run build      # сборка в dist/
npm run preview    # посмотреть сборку
node scripts/smoke.mjs ./shots   # сквозной сценарий в Chromium с скриншотами (нужен запущенный preview)
node scripts/icons.mjs           # перегенерировать PNG-иконки из public/icon.svg
```

Деплой: GitHub Actions (`.github/workflows/deploy.yml`) собирает и публикует `dist/` на GitHub Pages при пуше в `main`.
В настройках репозитория **Settings → Pages → Source** должно стоять «GitHub Actions». Базовый путь берётся из имени репозитория; для другого хостинга задай `BASE_PATH=/`.

Данные не покидают устройство: нет аналитики, сети и аккаунтов. Следующие идеи: обёртка Telegram Mini App с бэкапом в Telegram CloudStorage, экспорт CSV.
