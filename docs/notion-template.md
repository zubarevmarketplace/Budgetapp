# Тот же бюджет в Notion: как собрать за 30 минут

Это инструкция, если хочется вести бюджет в Notion, а не в приложении «Копилка». Логика та же: лимит на ништяки, цели, накопления с процентами. Собирать придётся руками: Notion не даёт импортировать формулы и связи, только таблицы.

Что получится и чего Notion не умеет, честно:

| Возможность | Копилка | Notion |
|---|---|---|
| Записать трату с телефона | 3 нажатия: «+», сумма, категория | 6–8 нажатий: открыть страницу, «Новая», дата, сумма, тип, категория, счёт; либо форма Notion |
| «Осталось из 5 000 на ништяки» | Кольцо на главной | Число в подвале таблицы (сумма за месяц), «осталось» считаешь в уме или через базу «Месяцы» |
| Цели: прогресс и «когда накоплю» | Да, автоматически | Прогресс-бар через rollup; прогноз даты сделать нельзя |
| Проценты по вкладу | Отдельный тип дохода | Отдельный тип в select |
| Офлайн | Да | Нет |
| Где данные | Только в телефоне | В облаке Notion, доступны с любого устройства |

## Шаг 1. Три базы данных

Создай страницу «Бюджет» и внутри три базы (Database → Table). Можно импортировать стартовые CSV из папки `docs/notion/` (Import → CSV): так колонки появятся сами, но типы свойств всё равно нужно поправить руками.

### База «Операции» (`operations.csv`)

| Свойство | Тип | Значения |
|---|---|---|
| Название | Title | коротко: «Латте», «Лента» |
| Дата | Date | |
| Сумма | Number, формат ₽ | всегда положительная |
| Тип | Select | Трата · Доход · Проценты · Отложено |
| Категория | Select | ☕ Кафе и кофе · 🍰 Ништяки · 👗 Одежда · 🎬 Развлечения · 🎁 Подарки · 🛒 Продукты · 🏠 Жильё · 📱 Связь · 🚌 Транспорт · 💊 Здоровье · 🏋️ Спорт · 📦 Другое |
| Ништяки? | Formula | см. ниже |
| Счёт | Relation → «Счета» | |
| Цель | Relation → «Цели» | только для типа «Отложено» |
| Месяц | Formula | см. ниже |

Формула «Ништяки?» (чекбокс, чтобы считать лимит):

```
prop("Тип") == "Трата" and ["☕ Кафе и кофе", "🍰 Ништяки", "👗 Одежда", "🎬 Развлечения", "🎁 Подарки"].includes(prop("Категория"))
```

Формула «Месяц» (текст для группировки):

```
formatDate(prop("Дата"), "YYYY-MM")
```

### База «Цели» (`goals.csv`)

| Свойство | Тип | Формула |
|---|---|---|
| Название | Title | |
| Сумма | Number ₽ | |
| Срок | Date | |
| Статус | Select | В процессе · Готово |
| Операции | Relation ← «Операции» | создаётся автоматически от связи «Цель» |
| Накоплено | Rollup | Операции → Сумма → Sum |
| Осталось | Formula | `max(0, prop("Сумма") - prop("Накоплено"))` |
| Прогресс | Formula, показать как Bar | `prop("Накоплено") / prop("Сумма")` |
| Нужно в месяц | Formula | `if(empty(prop("Срок")), "", round(prop("Осталось") / max(1, dateBetween(prop("Срок"), now(), "months"))))` |

### База «Счета» (`accounts.csv`)

| Свойство | Тип | Формула |
|---|---|---|
| Название | Title | |
| Тип | Select | Повседневный · Накопления |
| Ставка % | Number | |
| Баланс на старте | Number ₽ | |
| Операции | Relation ← «Операции» | |
| Приход | Rollup | Операции, фильтр Тип ∈ {Доход, Проценты, Отложено} → Сумма → Sum |
| Расход | Rollup | Операции, фильтр Тип = Трата → Сумма → Sum |
| Баланс | Formula | `prop("Баланс на старте") + prop("Приход") - prop("Расход")` |
| Процентов в месяц | Formula | `round(prop("Баланс") * prop("Ставка %") / 100 / 12)` |

Упрощение: в Notion «Отложено» привязано к одному счёту (куда положили), поэтому списание с карты при переводе не учитывается. Если хочешь точные балансы карты, записывай перевод двумя строками: «Трата / 📦 Другое» с карты и «Отложено» на накопительный.

## Шаг 2. Главная страница

На странице «Бюджет» добавь связанные представления (Linked view of database):

1. **Ништяки этого месяца.** Вид «Операции», фильтр: Ништяки? = ✓ и Дата = This month. В подвале колонки «Сумма» включи Calculate → Sum. Рядом текстом напиши лимит, например «Лимит 5 000». Осталось = лимит − сумма.
2. **Отложено за месяц.** Вид «Операции», фильтр: Тип = Отложено, Дата = This month, Sum по сумме.
3. **На процентах.** Тот же вид с Тип = Проценты.
4. **Цели.** Галерея базы «Цели» с показанными свойствами Прогресс, Осталось, Нужно в месяц.
5. **Счета.** Таблица базы «Счета» с Баланс и Процентов в месяц.
6. **История.** Вид «Операции», группировка по «Месяц», сортировка по дате вниз.

Чтобы видеть «осталось из лимита» одним числом, добавь четвёртую базу «Месяцы» с одной строкой на месяц, связью на «Операции» и rollup по «Ништяки?»-операциям. Но связь каждой операции с месяцем придётся ставить руками, поэтому это необязательный шаг.

## Шаг 3. Быстрый ввод с телефона

Это главная слабость Notion, и вот что помогает:

- **Кнопка «Трата».** На главной: `/button` → Add page to «Операции» со свойствами Тип = Трата, Дата = Today. Одно нажатие открывает карточку, где остаётся вписать сумму и категорию.
- **Форма Notion.** В базе «Операции» создай New form: поля Сумма, Категория, Счёт, Название. Ссылку на форму добавь на домашний экран телефона: открывается без лишнего интерфейса, заполняется за минуту.
- **Виджет Notion** на iOS и Android: вынеси страницу «Бюджет» или форму в виджет.
- **Шаблон строки.** В «Операции» сделай шаблон «Трата» с типом и датой по умолчанию и назначь его дефолтным (Templates → Set as default), тогда кнопка «New» сразу создаёт трату.

## Шаг 4. Раз в месяц

1. Записать проценты по каждому вкладу: Тип = Проценты, Счёт = вклад.
2. Записать перевод в накопления: Тип = Отложено, Цель = на что копишь.
3. Проверить, что ништяки уложились в лимит, и порадоваться строке «Отложено».
